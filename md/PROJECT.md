# 项目定位

## 当前项目

当前实体是一个使用 SystemVerilog 编写的、小型单发射顺序 RV32I 五级流水线核：

```text
IF -> ID -> EX -> MEM -> WB
```

它的用途是建立处理器机制的可观察实验基线，而不是在现有五个模块中不断堆功能，直到结构上变成香山。

## 长期目标

项目沿三条相互关联的方向推进：

1. 完善自研 CPU，使其成为控制、存储、异常和性能机制的最小实验平台。
2. 从已经亲手实现的机制出发，理解香山的 Frontend、Backend、ROB/Commit、MemBlock、LSU、Cache/TLB、分支预测、重命名、调度和恢复。
3. 最终在固定版本的香山源码上完成构建、事件追踪和低风险修改，并用官方测试或 Difftest 验证。

## 学习方式

- 用户优先亲手完成关键 RTL，形成周期和硬件状态直觉。
- Codex 负责代码审查、因果解释、机器码测试、自检检查和通过后的归档。
- 每项新机制都应回答：旧结构为什么不够、新增了什么状态、阻塞或恢复时这些状态如何变化。
- 代码、自动检查和 Vivado 日志是验证证据；文档只记录结论。

## 当前范围边界

当前核没有 Cache、外部总线、ready/valid 内存协议、异常、CSR、中断、分支预测、重命名、乱序调度或 ROB。未知指令也没有进入异常流程。

这些缺失项是后续实验方向，不应被描述成当前已经支持的能力。
